# Rajnish Kumar — Software Engineering Portfolio

Welcome to my personal portfolio repository! This is a modern, high-performance, dark-themed developer portfolio built with React and Vite. It features premium glassmorphism styling, ambient motion effects, and showcases my engineering projects, skills, and experience.

## 🚀 Live Demo
* **Live Link:** [rajnishkumar.dev (or your hosted domain)](https://github.com/rajnishkumar1906/rajnishportfolio)

---

## 🛠️ Tech Stack & Key Features
* **Frontend Framework:** React 19 + Vite for ultra-fast HMR and building
* **Styling:** Tailwind CSS + Custom Vanilla CSS for smooth glassmorphism design tokens
* **Animations:** Subtle floating glow effects, scroll-revealed layers, and hover micro-animations
* **Icons:** Lucide React for consistent vector indicators
* **Responsive Layout:** Designed to scale beautifully from mobile screens to ultra-wide desktop monitors

## 💻 Local Development Setup

To run this portfolio website locally on your system, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone git@github.com:rajnishkumar1906/RajnishPortfolio.git
   cd RajnishPortfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Open [http://localhost:5173](http://localhost:5173) to view the live local environment.
